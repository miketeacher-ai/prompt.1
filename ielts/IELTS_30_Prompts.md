LEARNING OBJECTIVES: State 3 measurable objectives (By the end, learner can...). OUTPUT — always deliver these 3 sections: 1) STUDY NOTES (1 page, student-facing): key rules/strategy in bullets, 5-8 academic terms with definitions + example sentences, 2-3 worked examples with thinking steps, common traps + how to avoid, quick mnemonic/checklist. 2) EXERCISES (12 practice items, progressive easy→exam-level): mix SAT-style MCQ + IELTS gap-fill/matching as relevant to topic, include instructions, word limits where relevant, answer key with 1-line explanation per item + why distractors are wrong. 3) MINI-MOCK EXAM (timed, exam-realistic): task/passage/questions, student instructions with timing, scoring guide (SAT 200-800 / IELTS 0-9 / % as relevant), 5-line teacher review script for the 3 most-missed items, next-3-steps remediation.
